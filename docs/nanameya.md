# ナナメの部屋 — キャラ設定とシナリオ

実装計画（「ナナメな部屋」実装計画／2026年9月）を、**キャラ → シナリオ → 画面** の順に具体化した設計メモ。
画面はこのメモのシナリオ番号に対応させる。

## 1. キャラ設定（登場人物6人）

このサービスに登場するのはこの6人。**画面はこの6人のうち誰かのために作る**（誰のためでもない画面は作らない）。

| # | キャラ | 誰か | いま困っていること | この人のゴール |
|---|---|---|---|---|
| **C1** | 生徒① 佐藤 みなと | 1年B組12番 | 調べて終わってしまう。次の一手がない | 「調べる」以外の迫り方を1つ持ち帰る |
| **C2** | 生徒② 林 ひなの | 2年A組7番 | 毎回ちがうテーマ。点はあるが線がない | 前回の問いの続きから始める |
| **C3** | 先生 村上 | 2年担任・探究担当 | 一人で176名の伴走はできない | 外の大人に安心して預ける／様子を把握する |
| **C4** | エスラボ事務局 かなえ | 運営 | 安全管理が破綻したら全部止まる | 同意・審査・予約・通報の状態を一目で見る |
| **C5** | ナナメの大人（未加入）谷口 さとし | 元エンジニア。地域の紹介で知った | やってみたいが、何をどうすればいいか不明 | 応募 → 審査 → 研修 → 初回同席、まで迷わず進む |
| **C6** | ナナメの大人（加入済み）三浦 いずみ | 元新聞記者・まちの編集者 | 準備に時間がかかると続かない | 直前に記録を読み、対話後に一言残して終わる |

### キャラ別の詳細

**C1 生徒① みなと（P1「調べて止まる」型）**
- 状況：問いはある。検索して要約して終わり。「どう迫るか」は毎回「調べる」。
- 不安：知らない大人と話すのが怖い。何を話せばいいかわからない。
- **設計の含意**：準備を求めない。自分の記録がそのまま話す材料になると明示する。相手は「迫り方」で選ばせる。

**C2 生徒② ひなの（P3「毎回リセット」型）**
- 状況：熱量はある。だが回ごとにテーマが変わり、前回とつながらない。
- 不安：前に話したことをまた説明するのが面倒。
- **設計の含意**：対話後の引き継ぎメモを**次回記録の「次に挑戦すること」欄の下書き**に流し込む。2回目以降は前回の対話が画面に出ている状態から始める。

**C3 先生 村上**
- 状況：授業設計・コメント記入で手一杯。外部の大人に預けたいが、預けっぱなしは怖い。
- **設計の含意（要確認）**：先生には**「実施したかどうか」までを見せ、対話の中身は見せない**。中身まで先生に流れると「評価されない場所」ではなくなり、ナナメの関係が壊れるため。先生が見るのは、クラスの同意取得状況／予約・実施状況／通報の有無まで。

**C4 事務局 かなえ**
- 状況：ボランティア3〜5名・生徒300名規模。人数より先に安全管理が壊れると全部止まる。
- **設計の含意**：同意なしの生徒に予約させない（システムで止める）。通報は誰が・いつ・何をしたかを追える。ボランティアの活動を即時停止できる。

**C5 ナナメの大人（未加入）谷口 さとし** ← **今回いちばん画面が足りていないキャラ**
- 状況：興味はあるが、何者かもわからないまま子どもと話せるとは思っていない。審査されることにはむしろ納得している。
- 通る道：募集を知る → 応募フォーム → 面談・身分確認 → 行動規範への署名 → 研修 → 空き枠登録 → 最初の2〜3回は運営同席 → 通常運用。
- **設計の含意**：この間ずっと「いま自分はどの段階か」が見えること。審査中に生徒の記録は一切見えないこと。

**C6 ナナメの大人（加入済み）三浦 いずみ**
- 状況：月4〜6枠。準備に時間がかかると続かない（燃え尽きが最大の離脱要因）。
- **設計の含意**：担当分の記録だけを、対話直前に1画面で読める。事後メモは1〜2行で終わる。困ったら1タップで運営へ。

### 補足：一覧に出すボランティアのプロフィール

上の6人は**登場人物**。生徒の一覧画面に並ぶボランティアのサンプルデータは `nanameya-data.js` にある別物で、
**1人＝1つの「迫り方」**を体現するように置いている（「調べる」56%偏重を崩すため、職業ではなく迫り方で選ばせる）。

つくってみる（町工場の職人）／聞いてみる（元記者＝C6）／観察する（農家）／当事者に会う（看護師）／
数えて比べる（データ分析）／小さく試す（カフェ店主）。C5 が加入すると、ここに7人目として並ぶ。

## 1-4. 管轄の線（重要）

**ジャーナルは学校・先生のもの。ナナメの部屋はエスラボのもの。** 2つは別のサービスで、
エスラボ ポータルの2本柱としてそれぞれ独立している。

| | ジャーナル | ナナメの部屋 |
|---|---|---|
| 管轄 | 学校・先生 | エスラボ |
| 入り口 | ポータル → ジャーナル | ポータル → ナナメの部屋 |
| 相互リンク | ポータルへ戻るのみ | ポータルへ戻るのみ |

この線から出てくる決めごと:

- **ジャーナルの画面にナナメの部屋への導線を置かない。** 生徒はポータルから入る。
- **探究の記録は「生徒が持ち込む」。** 予約画面で生徒が自分の記録から探究カードを作り、
  見せることに同意して初めて大人に渡る（[privacy](nanameya-privacy.md)）。学校のデータを
  エスラボが横から読むのではない。
- **議事録をジャーナルに自動で書き戻さない。** 大人の一言はナナメの部屋に残り、
  生徒が自分で「次に挑戦すること」に写す。生徒本人を経由することで、管轄をまたがない。

## 2. シナリオ

> **シナリオ1（背骨）＝ 空き枠登録から議事録が事務局に返るまで**は、
> [`docs/nanameya-flow.md`](nanameya-flow.md) に一本の流れとして展開した。
> 以下はキャラ別の全体像。

### C1・C2 生徒（S1〜S6）

- **S1 きっかけ**：**エスラボ ポータル**からナナメの部屋に入る。
  ジャーナル（学校・先生の管轄）からは直接リンクしない。ナナメの部屋はエスラボの管轄で、
  2つは別のもの。生徒は自分の記録を「持ち込む」形で使う。
- **S2 選ぶ**：ナナメの部屋トップで、**迫り方**で絞って大人を選ぶ。
- **S3 同意ゲート**：保護者同意が未取得なら予約ボタンを出さない。代わりに「おうちの人に見せる説明」を出す。
- **S4 予約**：空き枠（TimeRex）を開いて確定。確定後、日時と通話リンクがジャーナルに表示される。
- **S5 対話**：「困ったことがあったら」を常設。押すと運営に即時通知。
- **S6 つながる（C2の本命）**：対話後、大人の一言がナナメの部屋に残る。
  **ジャーナルへは自動で書き戻さない**（管轄が違うため）。生徒が自分で「次に挑戦すること」に写す。
  2回目以降は「前回、三浦さんと話したこと」がナナメの部屋に見えている状態から始まる。

### C3 先生（T1〜T2）

- **T1 把握**：先生メニューに「ナナメの部屋」を追加。クラスの同意取得状況・予約/実施状況・通報の有無を見る。**対話の中身は見えない。**
- **T2 声かけ**：まだ使っていない生徒、同意が取れていない生徒がわかる。個別に声をかける・保護者に案内する。

### C5 ナナメの大人・未加入（V0-1〜V0-5）

- **V0-1 知る**：募集ページ。何をする役か、しない役か（評価しない・答えを渡さない）が最初に書いてある。
- **V0-2 応募**：応募フォーム（自己紹介・関心分野・話せる迫り方・身分確認書類）。
- **V0-3 待つ**：ステータス画面で「面談待ち → 面談済み → 誓約署名待ち → 研修待ち → 承認」が見える。この間、生徒の記録は一切見えない。
- **V0-4 誓約・研修**：行動規範への同意署名、研修の受講記録。両方完了しないと次に進めない。
- **V0-5 慣らし**：空き枠を登録。最初の2〜3回は運営同席つきの枠として出る。問題なければ通常運用へ。

### C6 ナナメの大人・加入済み（V1〜V3）

- **V1 準備**：担当予約の一覧。対話直前に、その生徒の直近の記録（テーマ／わかったこと／わからないこと）を読む。担当分のみ。
- **V2 事後**：引き継ぎメモを1〜2行。これが生徒の次回記録の下書きになる（生徒は編集・破棄できる）。
- **V3 有事**：気になることがあれば運営へエスカレーション。

### C4 事務局（E1〜E3）

- **E1 審査**：応募者の一覧と審査ステータスの更新（面談・身分確認・誓約・研修）。承認して初めて一覧に載る。
- **E2 平常**：予約一覧・実施状況・保護者同意の取得状況。同意なしの予約が発生していないこと（目標ゼロ）を確認。
- **E3 有事**：通報の受付・対応記録・ボランティアの活動一時停止。
