# 大人に見せる「探究カード」— 個人情報の遮断ルール

ナナメの大人（C6）は、対話の**前**と**最中**に、担当する生徒の探究の中身を読む。
このとき渡していいものを**許可リスト（allow-list）**で決める。
「これは隠す」の列挙（deny-list）にしない — 列が増えたときに漏れるのは必ず deny-list のほうだから。

## 1. 前提：ジャーナルが持っている個人情報

`entries` テーブル（`d1/schema.sql`）には次が入っている。

| 列 | 中身 | 大人に渡すか |
|---|---|---|
| `name` | **生徒の実名** | ❌ 渡さない |
| `grade` | 学年 | ⭕ 渡す（中1と中3で話し方が変わるため） |
| `cls` / `no` | 組・出席番号 | ❌ 渡さない（学校内で個人が一意に特定できる） |
| `col5`〜`col13` | 探究の記述 | △ **許可リストの列だけ**、自動マスクを通して渡す |
| `teacher_comment` | 先生のコメント | ❌ 渡さない（学校側の評価文脈を持ち込まない。C3の方針と対） |
| `updated_at` | 更新日時 | ⭕ 渡す（いつ書いたものか） |

## 2. 大人が見る「探究カード」の中身（許可リスト）

生徒の**直近**のセッション1件から、次の4ブロックだけを組み立てる。

| ブロック | 出どころ（type1＝A/B） | 出どころ（type3＝C/D） |
|---|---|---|
| いまの探究テーマ | `col13` 今の私の探究テーマ | `col5` 今の探究テーマ |
| いまの問い | `col7` 一歩深まった問い | `col7` 更新した目標 |
| どう迫ろうとしているか | `col8` 目的 ＋ `col9` 調査・分析 | `col8` 研究すること ＋ `col9` 方法 |
| まだわからないこと・次の一歩 | `col11` 進むと何が起きそう ＋ `col12` 参考にしたいこと | `col10` 準備すること ＋ `col13` メモ |

**識別情報として渡すのは「学年 ＋ ニックネーム」まで。** ニックネームは生徒が予約時に決める（本名でなくてよい）。
姓・組・番号・学校名・先生コメントは、**APIのレスポンスに載せない**。画面側で隠すのではなく、
サーバーで落とす（画面で隠すだけだと通信内容には残ってしまうため）。

## 3. 自由記述に混ざる個人情報の自動マスク

許可リストの列でも、本文に個人情報が書かれていることがある。次を機械的に伏せる（`nanameya-mask.js`）。

| 対象 | 例 | 置き換え |
|---|---|---|
| 生徒本人の氏名（`name` から生成） | 佐藤／みなと | ●● |
| 学校名 | 原宿外苑中学校 | ●●学校 |
| 電話番号 | 03-1234-5678 | ●●● |
| メールアドレス | a@b.jp | ●●● |
| URL | https://… | ●●● |
| SNSのID | @minato_11 | ●●● |
| 住所（丁目・番地） | 2丁目3-4 | ●●● |

**自動マスクは完全ではない。** 友達の名前・部活名・地名は機械では判別できないので、次の2段で補う。

1. **生徒が決める** — 予約時に「この記録を見せる」を明示的に選ぶ。何が渡るかを生徒自身が同じ画面で確認できる。
2. **事務局が見られる** — 大人に渡ったのと同じカードを事務局（C4）も見られる。問題があれば止める。

## 4. 見られる期間と範囲

| 制限 | 内容 |
|---|---|
| **誰の** | 自分が担当する予約の生徒のみ。他の生徒は一覧にも出ない |
| **いつから** | 予約確定後（対話前に準備できるように） |
| **いつまで** | 対話終了の**24時間後**まで。以降は開けない |
| **どこまで** | 直近1セッションのみ。過去回の全履歴は渡さない |
| **記録** | 誰がいつどのカードを開いたかをログに残し、その旨を大人の画面にも明記する |

審査中のボランティア（C5）は、**どの生徒の記録も一切見られない**。承認され、担当予約が入って初めて見える。

## 5. 画面に書いておくこと

- 「この内容は持ち出さないでください。コピー・保存・スクリーンショットはしないでください。」
- 「開いた記録は事務局に記録されます。」
- 「連絡先の交換はできません。」

技術的にコピーを禁止することはできないので、**書いてあること・ログが残ること**の2つで抑止する。
実効性は、行動規範への署名（C5のV0-4）と組み合わせて担保する。
