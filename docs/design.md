# My 探究ジャーナル — デザインの決め事

中学生が「自分の探究の変化」を残す場。**やさしさ**（威圧しない・急かさない・書きやすい）を
デザインの芯にする。参考: team-mirai「みんなのRCV」のデザイン言語（ティール＋淡いtint面＋
やわらかい影＋ゆったりした組版）。トークンの正本は [`theme.css`](../theme.css)。

## 1. やさしさの作り方（原則）
- **硬い線・影を使わない**：黒2pxの罫線や `3px 3px 0` のオフセット影は禁止。境界は淡い `--line`、
  浮きは**やわらかいブラー影**（`--shadow-card` / `--shadow-elev`）。
- **面で区切る**：罫線より、ミントの淡いtint面（`--teal-100/50`）でグループを示す。
- **ゆったり組む**：本文 `line-height:1.8` ＋ `letter-spacing:0.04em`。詰め込まない。
- **角を丸める**：`--r-sm/md/lg/pill`。入力・カード・ボタンはすべて丸める。

## 2. 色（トークン）
| 用途 | トークン | 値 |
|---|---|---|
| 主役アクセント / tint境界 | `--teal` | #30BCA7 |
| 塗りボタン・白文字が乗る濃さ | `--teal-deep` | #0F8472 |
| バッジ・押下 | `--teal-deepest` | #0A5F52 |
| 面（案内カード等） | `--teal-100` / `--teal-50` | #E2F6F3 / #F0FBF9 |
| お祝い・ハイライト | `--amber` | #F6C445 |
| 先生系の差し色 | `--coralc` | #F2795F |
| 危険（削除等） | `--danger` | #E63946 |
| 本文 / 補助 / 微 | `--ink` / `--muted` / `--faint` | #1F2937 / #5B6670 / #8A939C |
| 紙 / ページ地 / 境界 | `--paper` / `--canvas` / `--line` | #FFFFFF / #F7FAF9 / #E7ECEA |

- 白文字を乗せる面は必ず `--teal-deep` 以上（#30BCA7 は明るく白文字が乗らない＝コントラスト不足）。
- 既存コードの `--green`/`--sand`/`--lime` 等は `theme.css` で上のトークンへ**再マッピング**済み
  （個別のコンポーネントCSSを触らずに全画面へ波及させるため）。

## 3. タイポグラフィ
- 和文: Noto Sans JP。本文 15px / `line-height:1.8` / `letter-spacing:0.04em`。
- 見出しスケール: display / h1 / h2 / body / support / label（`--type-*`）。
- **太字は「転回語」だけ**に使う（編集の軸＝煽らない・具体）。

## 4. 余白・角丸・影
- 余白: 8px基準（`--space-1..7` = 4/8/12/16/24/32/40）。全体にゆとり方向。
- 角丸: `--r-sm:6 / --r-md:10 / --r-lg:16 / --r-pill:999`。
- 影: `--shadow-card:0 8px 24px rgba(16,55,49,.08)` / `--shadow-elev:0 12px 32px …/.12`。

## 5. コンポーネント規則
- **カード**: 白 or 淡tint面＋`--line`＋`--r-lg`＋soft影。黒枠にしない。
- **ボタン primary**: `--teal-deep` 塗り＋白文字＋`--r-md`。hoverは軽い浮き（`translateY(-1px)`＋soft影）。
- **入力**: 1px soft border＋`--r-md`。focusは `--teal` の3pxリング。
- **バッジ/ピル**: tint背景＋濃色文字（枠内1行は光学補正を検討）。
- **モーション**: 控えめ。`prefers-reduced-motion` を尊重。

## 6. 印刷（A4タテ・ブラウザ印刷）
- `@media print { @page{ size:A4 portrait } }`。1カラム、設問単位で改ページ回避。
- 生徒ページはテキストエリアを `scrollHeight` まで伸ばして回答を全表示（`beforeprint`）。
- 画面専用UI（ボタン・案内・タブ・ダイアログ）は印刷しない。

## 7. ファイル構成
- `theme.css` … **決め事の正本**（トークン＋やさしさ上書き）。最後に読み込む。
- `style.css` / `design-refresh.css` … 既存のレイアウト・部品（値はトークン参照へ寄せていく）。
- 変更は `theme.css` のトークンを起点に。個別の色直書きを増やさない。
