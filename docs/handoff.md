## 5. 個人情報の扱い（いちばん重要・未完了あり）

`entries` テーブルには **生徒の実名（`name`列）と先生コメント** が入っている。
大人に渡すのは許可リストで選んだものだけ:

- **渡す**: 学年、ニックネーム（生徒が予約時に決める）、探究の4ブロック、記録日
- **渡さない**: 本名、組、出席番号、学校名、先生コメント、過去回の全履歴
- 本文中の個人情報（本人氏名・学校名・電話・メール・URL・SNS ID・住所）は自動で伏せる
- 見られるのは担当分のみ／対話終了の**24時間後**まで／閲覧ログを残す
- 審査中のボランティア（C5）は**どの生徒の記録も見られない**

### ⚠️ 未完了：マスクをサーバー側へ移すこと

いまのマスクは `nanameya-mask.js`（フロント）で動いている。**これは保護になっていない。**
モックなので生データがブラウザに読み込まれた上で表示時に伏せているだけで、通信内容には実名が残る。

**API化のときに必ず `/api/nanameya/brief` のサーバー側へ移すこと。**
`name` / `cls` / `no` / `teacher_comment` は**レスポンスに載せない**。
（`nanameya-mask.js` の冒頭コメントにも同じ注意書きあり）

## 7. 動かし方

```bash
# 画面だけ見る（D1不要）
python3 -m http.server 8899   # → http://localhost:8899/portal.html

# プレビューを作り直す（画面を直したあと）
node tools/build-preview.js   # → preview.html

# ジャーナル本体（D1あり）は README.md の手順で
```

画面の状態はクエリで切り替えられる:
`nanameya.html?consent=approved` / `nanameya-brief.html?state=before|soon|live|after|expired` /
`nanameya-session.html?state=...&b=b3` / `nanameya-book.html?v=v2&consent=approved`
